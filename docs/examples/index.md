This section contains the examples.

## Requirements

For the NanoCockpit examples, follow the [NanoCockpit](/docs/examples/nanocockpit/index.md) page
instead.

All other examples in this section need

* the original ESP32 firmware and the GAP8 bootloader. If you used NanoCockpit, see
  [switching firmware](/docs/development/switching-firmware.md).
* for the examples that use the Autotiler, the Docker image with the Autotiler, see the
  [SDK section](/docs/development/gap8.md#sdk) of the GAP8 page.
